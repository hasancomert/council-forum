> yalnızca kullanıcı onay verince yap, komutları PowerShell için ver. Her aşama (A–F) ayrı sohbette yapılır.

**Goal:** İnternetsiz yerde iki bilgisayardaki iki forum kopyası, STM32 Black Pill + Ra-02 LoRa modem üzerinden birbirine eşitlenir.

**Architecture:** Forum iki bilgisayarda aynen çalışır (Django + SQLite). SQLite tetikleyicileri her satır değişikliğinin
anlık görüntüsünü `sync_change` günlüğüne yazar; `sync_run` süreci günlüğü küçük, imzalı paketlerle karşıya taşır ve
geleni ham SQL ile uygular. Oylamaları yalnızca 1. düğüm (hakem) sonuçlandırır. STM32 yalnızca USB ↔ LoRa köprüsüdür.

**Tech Stack:** Python 3.14, Django 6.1, SQLite (JSON1, WAL), `pyserial`; firmware: PlatformIO + Arduino (STM32duino) + `sandeepmistry/LoRa`.

**Spec:** `docs/superpowers/specs/2026-11-13-lora-sync-design.md` (her aşamadan önce okunur; "neden"ler orada).

Tetikleyici SQL'i (ekleme; `{t}` tablo, `{new}` = `NEW."c1", NEW."c2", …`):

```sql
CREATE TRIGGER sync_{t}_i AFTER INSERT ON "{t}"
WHEN NOT COALESCE((SELECT applying FROM sync_state), 0)
BEGIN
  INSERT INTO sync_change (tbl, rid, data, seen, at)
  VALUES ('{t}', NEW.id, json_array({new}),
          COALESCE((SELECT applied FROM sync_state), 0), strftime('%Y-%m-%d %H:%M:%f', 'now'));
END
```

def message(change, rid=None, seen=None, data=True, **values):
    """Yakalanmış bir değişiklikten karşıdan gelmiş gibi mesaj: alanlar sütun adıyla değişir; data=None silmedir."""
    index, old_rid, old_seen, row = json.loads(zlib.decompress(pack(change)))
    row = None if data is None else [values.get(c, v) for c, v in zip(columns(change.tbl), row)]
    return zlib.compress(json.dumps([index, rid or old_rid, old_seen if seen is None else seen, row]).encode())

  `deliver(seq: int, body: bytes) -> bool`, `status() -> tuple[int, int, int]` (saat, son sıra no, şema özeti),
  `on_status(clock: int, last: int, applied: int, schema: int) -> None`.

Paketler (`struct`, büyük uçlu; her paketin sonuna `hmac.new(key, paket, 'sha256').digest()[:TAG]` eklenir):

| Tür | Düzen |
|---|---|
| Veri | `b'D'`, düğüm u8, sıra no u32, parça u16, parça sayısı u16, parça (en fazla `CHUNK` bayt) |
| Onay | `b'A'`, düğüm u8, sıra no u32, beklenen parça u16 (parça sayısına eşitse mesaj tamam) |
| Durum | `b'S'`, düğüm u8, saat u32, son sıra no u32, uygulanan u32, şema özeti u32 |

Kurallar:

1. Etiketi tutmayan, kısa kalan ya da düğüm numarası kendisininkiyle aynı olan paket yok sayılır (`heard` değişmez).
   `online` başlangıçta `False`'tur; geçerli herhangi bir paket `True` yapar.
2. Onay "bu mesajda sıradaki beklediğim parça" demektir (toplu onay). Veri gelince:
   - Sıra no `host.applied()`'dan büyük değilse: onay(sıra no, parça sayısı). Mesaj yeniden teslim edilmez.
   - Değilse, o sıra no için yarım mesaj yoksa boş bir tane açılır. Gelen parça beklenen parçaysa eklenir, değilse
     atılır. Mesaj tamamlanmadıysa onay(sıra no, eldeki parça sayısı) gönderilir; böylece yeniden başlamış alıcı
     "0. parçayı bekliyorum" der ve gönderen baştan başlar.
   - Mesaj tamamsa `host.deliver()` çağrılır: `True` ise onay(sıra no, parça sayısı) ve yarım mesaj silinir; `False`
     ise onay gönderilmez, yarım mesaj saklanır ve son parça yeniden gelince teslim yeniden denenir.
3. Gönderme dur-ve-bekle: tek mesaj, parça parça; boş gövde tek (boş) parçadır. Gelen onaydaki "beklenen parça"
   gönderenin sıradaki parçası olur; parça sayısına eşitse `host.delivered(seq)` çağrılır. Onay
   `ACK_TIMEOUT[node] + rng() * JITTER` içinde gelmezse aynı parça yeniden gönderilir. Art arda `DOWN_AFTER` onaysız
   denemeden sonra `online = False` olur ve deneme aralığı `DOWN_RETRY`'a çıkar. Hiçbir mesaj atılmaz.
4. Onay hemen gönderilir. Başka paket için `now() >= heard + GUARD` ve yayın bütçesi beklenir: `airtime_used()`,

class FakeHost:
    def __init__(self, **messages):
        self.out = {int(k[1:]): v for k, v in messages.items()}  # m1=b'..' -> {1: b'..'}
        self.sent, self.got, self.calls, self.statuses, self.ok = 0, {}, 0, [], True

    def applied(self):
        return max(self.got, default=0)

    def next_message(self):
        pending = sorted(seq for seq in self.out if seq > self.sent)
        return (pending[0], self.out[pending[0]]) if pending else None

    def delivered(self, seq):
        self.sent = seq

    def deliver(self, seq, body):
        self.calls += 1
        if self.ok:
            self.got[seq] = body
        return self.ok

    def status(self):
        return 1000, max(self.out, default=0), 42

    def on_status(self, *args):
        self.statuses.append(args)

### Task 12: Firmware ve gerçek seri port

**Files:**
- Create: `firmware/platformio.ini`, `firmware/src/main.cpp`

**Interfaces:**
- Consumes: seri protokol (Task 7 `SerialPort`): 115200 baud, SLIP; bilgisayardan gelen çerçeve = havaya verilecek paket;
  modemden giden çerçeve = `[RSSI int8][SNR int8] + paket`; 1 baytlık çerçeve yoklamadır, havaya verilmez, 1 baytlık
  sürüm (`0x01`) çerçevesiyle yanıtlanır.

`platformio.ini`:

```ini
[env:blackpill]
platform = ststm32
board = blackpill_f401cc
framework = arduino
upload_protocol = dfu
lib_deps = sandeepmistry/LoRa
build_flags =
    -D PIO_FRAMEWORK_ARDUINO_ENABLE_CDC
    -D USBCON
    -D LORA_FREQ=434500000
    -D LORA_SF=7
    -D LORA_BW=125000
    -D LORA_CR=5
    -D LORA_SYNC=0x5A
    -D LORA_POWER=10
```

USB bayrakları ve yükleme yöntemi PlatformIO'nun güncel `ststm32` belgelerinden doğrulanır (ezberden yazılmaz).

`main.cpp` davranışı:

- Pinler: NSS `PA4`, RST `PB0`, DIO0 `PB1`; SPI varsayılan (`PA5`, `PA6`, `PA7`); LED `PC13` (düşükte yanar).
- Açılış: `Serial.begin(115200)`; `LoRa.setPins`, `LoRa.begin(LORA_FREQ)`; başarısızsa LED hızlı yanıp söner ve durur.
  Ardından SF, bant genişliği, kodlama oranı, `enableCrc()`, sync word, `setTxPower(LORA_POWER)`.
- Döngü: seri porttan gelen baytlar SLIP çözücüye; tamamlanan çerçeve 1 baytsa yoklama yanıtı, 2–255 baytsa
  `beginPacket/write/endPacket` ile gönderilir, daha uzunsa atılır. `LoRa.parsePacket()` paket verdiyse RSSI, SNR ve
  paket SLIP çerçevesi olarak seri porta yazılır. Her gönderme ve almada LED durum değiştirir.
- Dinamik bellek kullanılmaz; arabellek 255 bayt.
